# Versioned paper results

`paper_v1/` is generated by `python main.py` and contains lightweight CSV/JSON
sources for the manuscript's reported values. Unlike the full `artifacts/`
bundle, this directory is intended for version control.

Use `paper_v1/RESULT_INDEX.json` to map a manuscript claim to its source table
and row. `experiment_metadata.json` records the dataset checksum, exact split,
primary conformal method, alpha, raw conformal probability source, separate
calibration methods, bootstrap settings, and limitations.

Figures, PDFs, LaTeX tables, and the fitted model remain in `artifacts/` because
they are reproducible but comparatively large.
